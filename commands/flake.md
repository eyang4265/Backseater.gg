# `/flake`

Show this Discord server's flake tier list.

## Usage

Run `/flake` with no options. Categories descend from S (most flaky) through A,
B, C, D, and F (least flaky), with Unknown shown at the bottom for unranked
members. Only the bot owner can change assignments with the private `/flakerank`
command, using Discord's native `user` picker one member at a time.
Anyone who can see a paginated tier list can use its page buttons.
