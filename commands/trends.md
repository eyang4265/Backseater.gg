# `/trends`

Scan every champion on OP.GG's selected global Ranked Solo/Duo role page, read
each champion's win-rate-by-game-length curve, and rank the ten highest win
rates at each timestamp.

Usage: `/trends role:<top|jungle|mid|adc|support>`

Use the game-time buttons to switch between every timestamp returned by OP.GG,
currently **Under 25 min**, **25–30 min**, **30–35 min**, **35–40 min**, and
**40+ min**. Champion names link to their individual OP.GG Trends pages.
